# ModernUI 4
ModernUI. A UI customisation pack for the TruckersMP multiplayer mod for Euro Truck Simulator 2 and American Truck Simulator.

# Where to download
You can download ModernUI from [my website](https://sgtbreadstick.uk/modernui) or through [TruckersMP forums](https://forum.truckersmp.com/index.php?/topic/87469-modernui-an-open-source-ui-pack-for-truckersmp/).

## Files within this repo
"UI Template.pdn" is a paint.net project file containing the different layors that makes up ModernUI.

All ModernUI base image files are in the "ModernUI-Base" folder all in correct directories as needed for TruckersMP. The "Font-Packs" folder is the different weighted fonts used within TruckersMP on legacy UI elements. There will be two ".ttf" files in each folder which when used in TruckersMP goes in the "shared_mod/fonts" directory.

## Creating your own ModernUI
If you need help creating your own version of ModernUI, there is a Sprite tool along with the "ui_skin.png" to help guide you on which elements are used for which function. This is "SpriteTool.html" and all you need to do it run that file in your browser and it will load the "ui_skin.png" file, then you hover over each element and a popup will appear telling you which element it is.

## How To Install ModernUI
To install the UI pack, go to "C:\ProgramData\TruckersMP\data" or "%AppData%\TruckersMP\installation", depending on your TruckersMP Installation directory

1. Delete any "ets2_mod" / "ats_mod" / "shared_mod" folders present in the directory
2. Open the .ZIP file and copy the folder(s) "ets2_mod" "ats_mod" & "shared_mod" into the "data" or "installation" directory.
3. Installation completed!

## Open Source
ModernUI is now open-source, feel free to use any of the files in this repo to customise ModernUI to your liking. Whether it is for personal use or for VTCs. If you want to upload your own version to the TruckersMP please credit either this GitHub repo, the ModernUI forum topic or the main website.
